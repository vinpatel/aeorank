:::note[Hosted convenience]
Compare-scans is a dashboard view when two completed scans exist. Canonical scoring is `aeorank-cli@0.1.2` (36 dimensions, 8 files). The CLI command is `compare`.
:::

When the section is present, pick two scans to see dimension-level before/after. This is technical score movement, not a citation timeline.
