title: Auto-Rescan
description: Optional hosted-app schedule. Plan gates are sites and scans per month.
---

:::note[Hosted convenience]
Auto-rescan is a dashboard extra when it is enabled on your account. It is **not** a Pro exclusive in copy, and it is **not** part of `aeorank-cli@0.1.1`. Sold gates are sites + scans/month.
:::

On a site page, if an **Auto-rescan** control is present, frequencies are off / daily / weekly / monthly. Treat charts as a view of scans you already ran — not a mention-monitoring product.
